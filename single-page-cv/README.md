# CV Page

A simple single-page CV built with **HTML and CSS**.

## Running Locally

No installation or dependencies are required.

1. Clone the repository:
2. Open the project folder.
3. Open `index.html` in your browser.

That's it.

## Built With

* HTML5
* CSS3
